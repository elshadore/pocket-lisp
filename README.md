# Pocket Lisp

⚠️ This project is currently under development and not yet finished ⚠️

Pocket Lisp in an embeddable Lisp Virtual Machine designed for scripting and automation. It can be used to extend or embed into other programs and applications, with a simple, easy to use, LUA-like, C api. Pocket Lisp is heavily inspired from Emacs Lisp and takes as Lisp-2 design (seperate namespaces for variables and functions).
